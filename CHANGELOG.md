# Changelog

All notable changes to Garden Terrarium are documented here.

## [0.2.0]

### Added
- Creatures that wander across the status bar, with settings for side, width, count and speed.
- Creatures that crawl in the blank space beside your code, and hide while you type.
- Garden views in the Explorer and the bottom panel, in addition to the Activity Bar.
- Commands: Release a New Creature, Shoo the Status Bar Creatures, Toggle Status Bar Creatures, Toggle Creatures On My Code.
- Marketplace icon, README and license.

### Changed
- Commands are now listed under the **Garden** category in the Command Palette.
- The webview's security nonce now comes from a cryptographically secure random source.

## [0.1.0]

- First release: an animated terrarium in the Activity Bar.
